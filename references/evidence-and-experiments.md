# 证据与最小试验

本文件提供工作规则。它不替代本项目适用的量测规范、统计设计、工艺批准或专业审查。

## 证据表的语义

| 类别 | 可以怎样写 | 不应升级成什么 |
|---|---|---|
| 用户报告 | 用户报告某批次黑渣增加，尚未取得原始记录 | 已确认由某参数导致 |
| 已查看数据 | 在提供的记录范围内观察到某事件 | 所有材料、设备与批次均成立 |
| 外部原始来源 | 某研究在其条件下报告某结果 | 本项目已经复现 |
| 工作假设 | 为初版模型暂把某项视为常数 | 该常数已有实测依据 |
| 候选机理 | 某机制可能解释观察 | 根因已查清 |
| 待验证问题 | 需要量测来区分 A01 与 A02 | 可以直接忽略的不确定性 |

引用应写来源位置、日期/版本和它支持的准确陈述。标准条文未取得时只说明未取得，不凭记忆捏造章节。公开检索使用脱敏后的结构与方法关键词，不外传用户的受控数据。

## 不混淆四个层级

**图像现象 → 过程状态 → 材料/结构缺陷 → 性能或合格判定**。

每一次跨层推断都要注明证据、适用范围与缺口。多传感器一致也不能自动补齐一条未验证的物理关系。把预测能力与机理解释分开，允许“有预测价值但尚未建立机理”。

## 如何选最小试验

先回答“结果会改变什么决定”。若所有合理结果都只会导向同一个动作，试验通常需要重新设计。

为 A01 和至少一个竞争解释写出不同预测。优先挑战最危险而且尚无依据的前提，不仅测试容易成功的模块。对比当前基线；存在简单规则基线时不直接跳过。

明确三种结果：

- 支持继续：达到预先设置的工程判据，且关键混淆未主导。
- 反对继续：未达到判据，或出现足以削弱关键前提的结果。
- 无法判断：量测检出能力不足、对照失效、样本不足、执行偏离或两种解释预测重合。

某路线通过探索性筛选，不等于证明了唯一机理；某次实验失败，也不必然证明方法原理不成立。

## 样本与量测

独立试验单元可能是炉次、零件、独立通道或独立重置后的动作，而不是每张图片、每个体素或每次重复计算。明确哪些是嵌套或相关观测，哪些可以独立比较。

先看检测方法能否分辨所关心的差异，再谈模型效果。记录校准、分辨率、检出限、重复性、漂移、缺测、配准和时序对齐。真值不可得时缩小主张：例如只验证过程异常复核效率，不声称证明最终产品无缺陷。

没有基线波动、目标效应量及误判容忍依据时，样本量只能是探索性建议。数值阈值来自用户要求、已核查规范或预先约定的试验设计；来源未定就显式标注“待定义”。小样本零失败不能直接作为高可靠性证明。

## 对工程 AI 的额外检查

| 风险 | 检查动作 |
|---|---|
| 相邻帧泄漏 | 尽量按炉次/零件/事件分组隔离开发与验证，不把同一事件两边分配 |
| 反复调参看测试集 | 保留未用于选择模型的验证数据，并记录访问历史 |
| 换了模型也换了前处理 | 做消融或配对对比，说明无法归因的部分 |
| 只有总体准确率 | 报告目标事件的漏报、误报、延迟、人工复核工作量和未覆盖场景 |
| 用漂亮可视化代替校准 | 分开说明显示正确、算法实现正确、模型预测正确、现场适用 |
| 工况漂移 | 明确换设备/材料/几何/粉末批次/相机位置后的再验证触发条件 |
| 直接自动停机或放行 | 先离线或影子模式；未经授权不接管联锁或签发质量结论 |

## 实施等级的标注

每个结果标记为：纸面推导、可复算计算、合成数据单元测试、历史回放、台架测量、受控实物试验、指定条件重复验证、生产批准中的某一项。不要把前一级写成后一级。

需要升级验证时说明新增证据与责任人，不用未经核查的认证术语包装。

## 开源项目不是工程效果证明

先按检索流程核查本领域项目；只有触发跨域分支才生成跨域候选，之后再检索实现。代码存在、作者报告有效、自己复现样例、在目标数据或实物上有效，是不同主张。许可、代码路径、维护状态、数据与权重可得性要在实际任务重新核查。

最小复用试验可以先验证原样示例，再固定输入适配，在同一基线下比较目标任务。仅测试导入成功，不能证明实际机制正确。没有找到代码可保留方法候选；检索工具不可用则不得声称已确认没有项目。
