# 方法迁移指南

这是本 Skill 的设计指南，不是任何具体方案已获验证的证明。下表是寻找原始文献和候选方法的索引；使用时核查方法定义、适用条件和已有证据。

## 进入本指南前

先执行主流程的本领域开源检索。有实质相关实现则默认先评估复用，不自动生成本指南的三个外部领域。仅本轮范围内未找到，或用户明确要求继续跨域时，进入以下结构映射；完成映射后，还必须检索对应领域的开源实现。

## 跨域分支内：先找结构，不先找名字

把“某行业也用 AI”替换为下列问题：它看不见什么真实状态？能看到什么代理信号？怎样改变状态？如何处理不确定性？怎样认定成功与失败？

| 目标问题的结构 | 可探索的外部方法族 | 容易被忽略的迁移断点 |
|---|---|---|
| 连续噪声观测中追踪同一对象/事件 | 雷达航迹关联、状态估计 | 空间配准、事件生成/消失、观测间隔与噪声假设 |
| 多个解释都能产生同一表象 | 实验科学的竞争假设、软件故障定位 | 有日志不等于有真实物理状态；时间先后不是充分因果证据 |
| 不完整信息下选择下一次观察 | 主动量测、信息导向试验设计 | 新量测未必可得；成本与安全不能忽略 |
| 多资源并行工作，等待最慢资源 | 分布式计算调度、运筹优化 | 任务不可拆分、资源不完全互换、同步和切换开销 |
| 有阻塞和出口约束的迁移问题 | 图搜索、网络连通性、机器人姿态规划 | 拓扑可达不等于物理流动；离散化可能虚构通道 |
| 专家通过少量示范传递边界判断 | 主动学习、偏好询问、教学中的对比案例 | 示范覆盖不足、专家也可能不一致、看不到隐含依据 |
| 低频高损失事件需要早发现 | 通信检测、分级筛查、可靠性试验 | 类别不平衡、误报与漏报代价不对称、真值成本 |
| 现有操作代价高但功能必需 | 功能分解、设计替代、流程重构 | 消除操作并不等于消除原来承担的功能 |

## 一条有效映射至少回答六个问题

以“并行计算调度 → 多激光排版”为抽象示例：

- 实体：计算任务对应某层的扫描任务，工作节点对应激光资源。
- 关系：任务分配与并行等待对应扫描分配与层结束同步。
- 目标：减少完成时间，而不是简单增加工作的资源数量。
- 约束：可服务区域、碰撞、安全边界、搭接规则及扫描路径限制。
- 不等价处：一件零件不能任意切割、挪动、跨高度迁移；热行为与质量限制可能反过来限制调度。
- 可核验预测：由候选分配生成的逐层时间预测能否与真实日志一致？未校准前只是模型假设。

这里的映射不证明调度方法适用于具体设备，也不提供机时精度承诺。

## 防止类比过拟合

不要只寻找支持类比的对应点。必须主动寻找一个“来源领域成立而目标领域不成立”的条件。然后判断属于：可补偿差异、必须重建模型、还是足以淘汰该路线的差异。

改变尺度时，不只比较形状。检查主导力、传热/传质时间、观测频率、控制频率、误差容许值、信噪比与成本结构。需要量纲推导时写单位，缺参数时保留符号与范围，不编造具体数值。

三个领域不等于三个标签。例如，把同一个时序分类器分别称为自动驾驶、视频监控和机器人，并没有带来三种真正不同的求解路径。

## 目标层级

优先比较这些层级，而不是固定从最复杂的一层开始：

`消除需求 → 改变设计/工序 → 改善观测 → 改善决策规则 → 提升算法 → 自动执行`

它不是固定优先级。质量、冻结基线和用户限制可以使某些层级完全不可选。保留用户指定方案作为基线或候选，解释增加其他层级是否有价值。

## 收敛方式

先排除当前硬约束下不可进入试验的路线，再比较哪项最便宜地消除重大不确定性。默认用理由和条件，不用没有依据的加权总分。

不追求“最先进”。一个简陋但能区分解释的试验，可能比完整仿真更适合当前决策；反过来，量测不足时再便宜的试验也可能毫无区分力。这是本流程的试验选择原则，不是效果保证。
